In the last couple of years, GitHub has been having a series of issues, and it feels like one of the primary reasons is the explosion of AI coding tools like Claude Code, Codex, and Cursor becoming popular.  
It seems like one of the big reasons why GitHub has become so unreliable is the explosion of commits from these tools. Most of it, obviously, is just slop. In a real sense, slop is clogging the veins of GitHub’s infra and leading to a series of micro heart attacks.  
This chart from GitHub's recent postmortem on their latest downtime event really stood out to me. It's ridiculous considering GitHub is free, and considering the spectacular explosion in people using it via these coding tools, can it truly be reliable?  
And that's before considering the fact that AI coding tools are still a novelty, so to speak—they aren't even used widely yet apart from the current early adopters.
